## 一、沪教版的编排逻辑（与全国版最大的差异）

这一点非常关键，**直接影响网站的信息架构设计**。

### 全国人教版（六三制）：系统→区域
```
七上：地球→地图→陆地海洋→天气气候→居民文化→发展合作
七下：亚洲→邻近国家→东半球→西半球→极地
八上：从世界看中国→自然环境→自然资源→经济发展→美丽中国
八下：地理差异→北方→南方→西北→青藏
```

### 沪教版（五四制）：工具→案例→系统→祖国
```
六上：怎么用地图（景观·地图篇） + 认识国家案例（世界分国篇）
六下：倒回头讲全球系统（地球运动 / 陆海 / 气候 / 人口资源环境）
七上：祖国篇（上）
七下：祖国篇（下）· 区域篇
```

**沪教版的核心设计思路**（很聪明）：
1. **先给工具**：六年级新生上来先学"怎么看地图"（比例尺、方向、图例、经纬网、分层设色地形图）
2. **再给案例**：用 8 个典型国家（日、印、埃、德、俄、美、巴、澳）练习刚刚学到的读图技能
3. **后给系统**：学生对世界有了感性认识后，六下才系统讲地球运动、地形、气候这些抽象原理
4. **最后祖国**：七上七下才进入中国地理

**对网站的影响**：
- 交互设计要突出"**读图工具**"，这是沪教版的骨架
- "国家"模块天然适合做成**数据卡片 + 3D 地球定位**
- 六下的自然地理部分是**3D 交互的富矿**（地球运动、地形、气候）

## 三、沪教版三大特色内容（全国版没有或很弱）

这些是做互动网站时**最能做出差异化**的地方：

### 特色 1：地理景观（全国版基本没有）
沪教版用整整一个单元讲"地理景观"：
- 千姿百态的地理景观（自然景观 vs 人文景观）
- 地理景观的地区差异
- 地理景观的变化与发展

**这天然是 3D/全景交互的最佳素材**：同一个纬度带上，热带雨林、热带草原、热带沙漠的景观对比；或者一个地区从过去到现在的演变。市面上几乎没有针对这块做的教学产品。

### 特色 2：分层设色地形图（沪教版重点）
沪教版 2.3「形形色色的地图」专门讲**分层设色地形图**，这是沪教版读图训练的压轴。
- 等高线 → 分层设色的转换原理
- 颜色对应的高度带（绿→黄→褐→白）
- 从分层设色图上判读地形类型

**交互价值极高**：让学生拖动"高度阈值"，实时看到地图配色变化，理解"颜色=高度"的映射关系。这个用纯前端就能做得很漂亮。

### 特色 3：学法串联（"怎样学习国家地理"）
沪教版 8「自主学习 认识国家」开篇就讲**方法**：怎样学习国家地理。
通常总结为一个固定框架：
```
位置范围 → 自然条件（地形/气候/河流） → 经济特点 → 居民与文化 → 主要城市
```

**这是网站做"国家档案卡"的天然模板**——每个国家一张卡，统一框架，学生可以对比。而且"自主学习"意味着学生要用学到的方法迁移，网站可以做"半自助探究"模块。

## 四、上海的地理测评特点（影响交互设计）

上海初中地理实行**学业水平考试**（合格性/等级性），命题风格有明显特色：

| 特点 | 含义 | 对网站的启发 |
|---|---|---|
| **读图题占比高** | 几乎每题都有图 | 交互必须围绕"图"，不能只是文字问答 |
| **配地图册常态化** | 图册纳入日常作业与测评 | 网站应该做"电子图册"，让学生查图、标图 |
| **强调真实情境** | 用案例考知识，不是死记硬背 | 多做情境题：给一段材料/一张卫星影像，判断这是哪儿 |
| **关注上海本地** | 长三角、城市热岛、能源结构等本地议题 | 可以加"上海乡土"专题（见下） |
| **数字化资源** | 地图册有二维码链接动态资源 | 网站天然符合这个方向 |

### 可加入的上海乡土专题（加分项）
- **长三角一体化**空间格局
- **城市热岛遥感影像对比**（上海中心城区 vs 郊区）
- **双碳目标下的上海能源结构**
- 上海港（世界第一大集装箱港）与世界海运航线
- 长江口对自己生活的影响

## 五、知识点的互动标签体系

每条知识点带 `互动` 标签，取值范围固定，方便前端做筛选和组件映射。

| 标签 | 含义 | 典型技术 | 主要分布 |
|---|---|---|---|
| `@3D球面` | 3D 地球/球体呈现 | Three.js / globe.gl | 地球概述、海陆分布、国家定位 |
| `@3D地形` | 三维地形/分层设色 | Three.js 高度图位移 | 世界的地形、分层设色地形图 |
| `@3D剖面` | 剖面图生成 | 高程采样 + Canvas | 地形剖面、海底地形 |
| `@时间轴` | 动态过程 | GSAP / 视频 | 地球自转公转、昼夜四季、景观变化 |
| `@图层叠加` | 多要素叠加分析 | MapLibre 图层控制 | 综合读图、资源分布 |
| `@图表判读` | 气候图/统计图 | ECharts | 气温降水、世界气候类型 |
| `@全景` | 景观对比（沪教版特色） | 全景图/3D 场景切换 | 地理景观单元 |
| `@拖拽` | 拖动练习 | Pointer Events | 经纬网、地图绘制、板块移动 |
| `@对比` | 并排对比 | 分屏滑块 | 国家对比、地形对比、景观对比 |
| `@计算器` | 公式与换算 | 自定义公式引擎 | 比例尺、时区、人口密度 |
| `@数据查询` | 点击查看属性 | SVG/3D 拾取 | 国家档案卡、地图查询 |
| `@闯关` | 综合练习 | 题目引擎 + 计分 | 贯穿 |

> **新增说明**：相比人教版体系，本版新增 `@全景` 标签（沪教版"地理景观"单元专用），并把 `@3D地形` 的权重提高（因为"分层设色地形图"是沪教版重点）。
